## 🇬🇧 English

### ✨ About

**Bubble Pop Kids Game** is a simple, joyful browser game for children. Colorful bubbles float up from the bottom of the screen, and kids pop them by tapping or clicking to earn points.

### 🎯 Features

| Feature | Description |
|:---:|:---|
| 🌐 | Fully browser-based — no server, no install |
| 📦 | **Zero dependencies** — no CDN, no external libraries |
| 🔊 | Built-in sound via **Web Audio API** — no audio files |
| 🎨 | Vibrant colors, gradients, particle effects |
| 📱 | Fully **responsive** — mobile, tablet, desktop |
| ⚡ | Single HTML file — under 20KB |
| 🇮🇷 | Persian (RTL) user interface |

### 🕹️ How to Play

- 🎈 Each colored bubble = **10 points**
- 🌟 Golden bubble = **50 points**
- ⏱️ Game duration: **30 seconds**
- 👆 Tap (mobile) or click (desktop) to pop bubbles

### 🚀 Run

```bash
# Just open the file in any modern browser!
open index.html
```

Or deploy via **GitHub Pages**:

```
Settings → Pages → Source: main branch → Save
```

### 🛠️ Tech Stack

- `HTML5` — Structure
- `CSS3` — Animations, gradients, responsive layout
- `Vanilla JavaScript` — Game logic
- `Web Audio API` — In-browser sound synthesis
